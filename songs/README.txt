Drop the songs in here.

Expected filenames (rename them in the CONFIG block of index.html if you'd
rather use your own):

  014.mp3
  023.mp3
  051.mp3
  068.mp3
  000.mp3     the hidden track, unlocked by the four-digit code

mp3, m4a and ogg all work. If a file isn't there yet, the handset says so
instead of breaking.

Don't want to host audio files? Leave `audio` blank for that track and put a
Spotify embed link in `embed` instead. On the Spotify track page:
Share > Embed track > copy the src, which looks like
https://open.spotify.com/embed/track/XXXXXXXXXXXXX
